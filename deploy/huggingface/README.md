# Kavrelle

A 3D shopping mall: twelve shops on two floors, accounts, orders, emails and a
support assistant measured with the 12 reliability metrics from *Towards a Science
of AI Agent Reliability* (Princeton, ICML 2026).

Source code: https://github.com/sherazashraf732-lab/agentrel

This is a demonstration store: no payment is taken and nothing is shipped.
